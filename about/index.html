About This Resource

A source-identity method and modular nameplates built around a shared ACBuy spreadsheet.

What this resource is

This is an independent informational and navigation resource for people who use an ACBuy spreadsheet. It offers four identity markers — visible name, exact domain, page context, and final destination — so each link is checked as a source before it is treated as one.

What this resource is not

This resource is not the official ACBuy website, and it is not affiliated with, endorsed by, or operated by ACBuy or Google. It is not an identity verifier, a product database, a store, a QC certification, a shopping agent, an order tracker, or a fee calculator.

The source-identity method

Everything here follows four markers. Azure marks the visible name. Vermilion marks the exact domain. Lime marks the page context. Silver marks the final destination. Four matching markers are only an observation — they never prove ownership or an official relationship.

How to use it

  1. Open the shared Google Sheet to see the listing references.
  2. Browse the twelve product categories from the home page.
  3. Read the three guides before treating any link as one source.
  4. Confirm identity on the actual destination page.

Identity-reading example — not ownership proof, verification, or a saved lookup.
