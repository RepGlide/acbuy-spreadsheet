Identity Check Guide

Apply the four markers — visible name, exact domain, page context, and final destination — one at a time before treating links as the same source.

Read one marker at a time

Source identity is not a single fact. It is four separate observations. Read each on its own, because none of them confirms another.

The four markers

  • Visible name — azure.

    The name the page currently displays. What it shows, not what it is, and not what it claims to be.

  • Exact domain — vermilion.

    The real domain, subdomain, and path — read precisely from the address, never from memory or a guess.

  • Page context — lime.

    The title and surrounding content that describe what the page is and what it is about.

  • Final destination — silver.

    Where a link or redirect actually lands after you follow it, not where the anchor text says it goes.

Why the markers are checked separately

A page can show one name and live on a completely different domain. A link can promise one destination and land somewhere else. If you merge the markers, you can no longer see where they disagree — and disagreement is exactly what you need to notice.

Four matching markers are an observation, not a proof. They never certify ownership or an official relationship.

A worked reading

  1. Visible name: the page shows a short brand-like name.
  2. Exact domain: the address has a subdomain and a path you read in full.
  3. Page context: the title describes the page’s purpose.
  4. Final destination: the link resolves to a page that may or may not match the name.

Identity-reading example — not ownership proof, verification, or a saved lookup.
